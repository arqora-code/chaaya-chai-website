# Chaaya — chai from the shade (concept)

A multi-page concept website for a fictional chai brand. Designed and built by **@arqora.thedesigner**.

> Concept website · sample products and prices · not a real store

## Pages
- `index.html`: home
- `blends.html`: all blends
- `blend.html`: a single blend (Kadak Masala)
- `origins.html`: the estates
- `ritual.html`: how to brew
- `visit.html`: the chai room

## Built with
Plain HTML, CSS and JS. No build step.
- Motion: GSAP 3.13 (ScrollTrigger, SplitText, Flip, CustomEase) with Lenis smooth scroll, self-hosted in `assets/vendor`.
- Scroll-scrubbed frame sequences in `media/`.
- Fonts: Fraunces, Manrope and Noto Serif Devanagari, self-hosted.

## Run locally
```
python3 -m http.server 8000
# open http://localhost:8000
```
